# CTN News Portal v1.1 — Update Summary

## Requested improvements completed
- Populated Local, World, Business, Markets, Sports, Entertainment, Technology and Reports with realistic source-backed demo news.
- Updated the navigation so **Latest** shows all current stories.
- Added an easy **Import News** CMS workflow for Hiru News and Ada Derana links.
- Added a manual source-draft fallback if automatic preview is blocked.
- Added source-name, source-URL and source-date fields to the editor.
- Added a visible original-source panel to source-based article pages.
- Added category-coverage counts on the admin dashboard.
- Added external image URL support with a permission warning; normal image upload remains available.
- Replaced text share buttons with circular SVG icon buttons for Facebook, WhatsApp, X, device share and copy link.
- Updated the information ticker with a dated demo market snapshot.
- Added automatic `.env` loading via dotenv for easier setup.
- Expanded the README with a non-technical editor workflow.

## Editorial note
The seeded articles are short CTN-style summaries rather than copies of third-party articles. Their original publisher links are retained in the data and shown on article pages. Editors should verify and rewrite imported drafts before publishing and should use images only when CTN has appropriate permission/rights.
